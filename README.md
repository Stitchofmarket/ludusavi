# Ludusavi

### Game save backup and restoration utility

Ludusavi is an open-source tool for backing up and restoring save data across hundreds of games and platforms. With automatic scheduling, cloud sync support, and a comprehensive game database, your saves are always safe.

<br>

---

## Features

| | |
|:---|:---|
| **2,000+ Games** | Automatically finds save locations for an enormous database of PC games |
| **Cloud Backup** | Sync backups to cloud storage providers including Google Drive and Dropbox |
| **Scheduled Backups** | Run automatic backups on a schedule or triggered by game launches |
| **Restore Anytime** | Quickly restore saves from any backup point across multiple versions |
